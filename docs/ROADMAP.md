# 产品演进路线

## 1. 可运行原型（本版本）
生活岛屿、五个概念、键鼠漫游、模型编辑、双语解释、导入与工程检查。

## 2. 可靠世界编辑器
世界 JSON schema 与版本迁移、撤销重做、对象层级、精确坐标、模型与场景保存、物理碰撞、资源预算、加载取消。验收：刷新与导出导入能无损恢复场景。

## 3. 概念学习系统
概念图谱、课程任务、操作检查、检索练习、掌握度、更多语言、关联模型语义、发音。验收：学习进度基于任务证据，不只按钮点击；翻译经过校对。

## 4. 开源模型目录
目录提供者、许可证与来源记录、对象存储、缩略图预览、压缩资产管线、LOD、按需加载。验收：每个资产可追溯许可与版本；违规资源被拒绝。

## 5. 工业级上线
服务端用户与世界隔离、监控、性能与安全测试、CI/CD、恢复演练、设备兼容。上线前必须完成 QUALITY 中的门槛。
