# 质量与验收

## 当前可执行检查

npm test：GLB 文件结构、真实示例加载前校验、超过 30 MB 的输入、外部资源阻断、内嵌资源、概念双语完整性。
npm run build：严格 TypeScript 检查与生产打包。
npm audit：依赖漏洞扫描；修补结果应记录在交付说明中。

## 人工验收

1. 桌面加载后显示生活岛屿，无持续黑屏；画布随窗口变化。
2. 五个内置物体均能由目录选择，面板同步；场景射线点击同步。
3. 移动、旋转、缩放工具可拖动坐标轴，环绕控制不会同时拖动。
4. 小球从约四米高度下落并衰减反弹。
5. WASD 移动，Shift 加速，Esc 恢复环绕；输入框与窗口失焦不会卡住移动键。
6. 小鸭加入场景；错误格式、过大文件、含外部图片的 GLB 产生错误提示。
7. 中英文切换更新学习内容；刷新保留已观察的内置概念。
8. 手机窄屏无横向溢出，目录可横向滚动；按钮可用。
9. 无 WebGL 或硬件加速关闭时显示错误。

## 工业级上线门槛（尚未完成）

- Chrome、Safari、Firefox、Edge、iOS 与 Android 设备矩阵验证；包括 WebGL context loss 恢复。
- Playwright E2E、视觉回归、无障碍审计与对话框焦点完整性。
- 真实模型规模下内存和 GPU 压力测试，模型多边形、纹理和动画预算、失败恢复。
- 低端设备帧时间采样，目标中端桌面 60fps、移动 30fps；这只是待验证目标。
- 后端认证授权、资产上传扫描、速率限制、审计日志、备份和恢复。
- 错误采集、指标与追踪、灰度发布、回滚、SLO、事件响应手册。
- 课程知识准确性审查与用户学习效果验证。

GLB 大小限制不等价于解码内存或 GPU 资源上限；当前解析在主线程，恶意或极复杂模型可能卡顿。只应导入可信来源模型。该限制应在后续以离线预处理、预算检查、隔离任务和取消机制解决。
