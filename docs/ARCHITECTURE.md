# 架构与扩展设计

## 当前架构

React 负责可访问 DOM 界面与学习状态；Three.js 引擎独立管理渲染与动画。稳定物体 ID 把三维 Object3D 与 Concept 联系起来，选择事件向界面回传 ID。UI 操作经 WorldEngine 公共方法进入引擎。动画循环内不触发 React 状态更新。ResizeObserver 更新画布尺寸；像素密度上限为 2；销毁时停止循环、解除监听与控制器、释放几何体、材质和纹理。

加载流程：文件选择 → 大小检查 → GLB 魔数、版本、长度、JSON 检查 → 阻止非 data URI 的外部资源 → GLTFLoader → 计算包围盒 → 尺寸归一化 → 加入对象注册表 → 聚焦。运行时模型只驻留内存。动画使用 AnimationMixer 播放。

## 语义与语言

Concept 的 ID 不随语言改变。name / category / description / action / fact 目前是中文、英文二元组。未来应迁移到语言标签映射 Record<BCP47, string>，使用独立消息字典管理 UI 文案与缺失翻译回退。翻译是同一个概念的表达，不能以语言字符串作为存储主键。

概念层应扩展为实体、属性、关系、行为、结果与证据。例如“球 → 质量 → 释放 → 下落 → 重力”。课程需要明确观察任务、交互操作、检查问题与掌握标准。当前进度仅表示点击观察，不代表掌握概念。

## 建议模型资产契约

未来 AssetManifest：id、version、format、url、sha256、license、attribution、units、upAxis、boundingBox、triangleCount、textureBudget、conceptIds、interactionCapabilities。资产注册需要审核许可证、内容哈希与资源预算，禁止在概念文本或模型 metadata 中执行代码。可按 CatalogProvider 接口增加 Khronos、Poly Haven、Kenney 或自托管目录；不能假设所有模型同许可证。

## 持久化与服务边界

当前没有服务器与数据库。工业版本应在服务端保存世界版本、资产元数据、学习事件和课程版本；使用对象存储管理经过验证的模型，以任务队列做转换 / 压缩 / 缩略图 / 扫描。账户服务实施按用户与项目隔离的授权。浏览器导入依然可以作为离线会话入口。

## 第一人称与模拟边界

摄像机约束岛屿边界；新增房屋的墙、门与主要家具使用世界坐标 AABB 阻挡移动。没有通用刚体、楼梯、跳跃或真实液体模拟。小球是数值积分演示，不是完整物理系统。后续接入固定时间步长物理引擎，分离模拟状态与视觉插值，并为每个教学实验给出适用条件与误差。

## WebMCP

对支持 document.modelContext 的浏览器注册 select_world_concept，复用可见界面状态与聚焦功能。普通浏览器不要求支持此实验接口。需要支持环境验证后才能声明兼容。

## 可进入房屋

interior.ts 构建空心墙体、门洞、地板、屋顶、可旋转房门、室内家具与灯光，并返回可碰撞对象。每帧重新计算房屋碰撞盒，使其跟随父级变换；人物半径为 0.23，X/Z 分轴移动并检查阻挡。门关闭时挡住入口，打开约 90 度后留出通道；便利入口等待开门动画接近完成再切换人物位置。进入与离开状态按人物相对房屋的坐标计算。

家具通过独立概念 ID 注册在房屋子层级中，射线点击优先识别最近的子物体，气泡沿用触碰锚点投影。落地灯采用独立 PointLight，由门旁墙壁开关切换强度，不影响全局环境照明。

## 扩建与动物导航

窗框位于真实墙面开口内，两扇窗各自用父级铰链旋转；顶灯与台灯 / 落地灯分别受墙壁开关控制。学校为三层可进入主楼，含教室、走廊与贯通楼梯，侧翼保持封闭。

柴犬 GLB 经已有自包含校验加载，统一比例及朝向后播放骨骼动画。dog-navigation.ts 在整数网格做 BFS，障碍来自建筑、树木、水面与长椅的世界包围盒（每 500ms 更新），移动时再次检查障碍与人物距离；停留时切换 Idle。该算法为简化导航，不含导航网格或复杂动物行为。

## 学校楼层与人物碰撞

school.ts 返回主楼结构、逐层墙壁 / 护栏 / 家具碰撞体，以及楼板 / 32 级楼梯踏步的可站立表面。学校与住宅碰撞盒每帧随父级变换更新。walking.ts 用人物当前足部与头部高度检查垂直重叠，X/Z 分轴滑动；上升单次限 0.26、下降限 0.35，楼梯每级高 0.2。站立高度来自当前可达表面，楼梯洞边缘无支撑时拒绝移动，低矮楼梯底部阻挡人物。

楼层按相对学校的足部高度更新。上楼 / 下楼入口按钮仅定位到当前层的平台，层间高度变化必须沿台阶行走。主楼入口常开，侧翼暂不开放。本实现仍为建筑 AABB 与表面高度约束，不是通用物理引擎；任意旋转 / 非均匀缩放后的台阶步高不保证可达，跨设备持续行走仍需验收。

## 地图库与语义层级

maps.ts 定义 WorldMap v1、标签目录、父子解析、文件校验与 IndexedDB 事务。MapLibrary.tsx 管理地图列表和创建者设置，内置模板与本机地图并列。保存内置地图时生成副本 ID，导入也生成新 ID，不覆盖原地图。删除可以在当前弹窗中撤销；文件导出和系统分享是用户主动动作。

engine.snapshotMap 记录受支持对象的本地变换和可见性，将已导入 GLB 的原始字节及许可编码进地图。加载在不可见独立渲染容器中完成，成功后替换旧引擎；解析失败释放新场景并保留旧地图。隐藏对象不参与射线与房屋碰撞。标签解析从命中部件向父级寻找已启用名称，门窗 / 灯具交互先按真实命中执行，命名与交互独立。

学习进度按地图 ID 分开保存在 localStorage，地图内容在 IndexedDB。地图文件不含执行代码、远程模型 URL 或用户账户信息；元数据只作纯文本显示。模型每个最多 30 MB、最多 20 个，总二进制约 45 MB，JSON 文件最多 65 MB。版本不匹配、重复 ID、错误层级、不可用变换、未知对象与缺失资产记录会拒绝导入。

当前为本机图库和文件交换，尚无服务器公共地图目录、用户账户、共享链接或任意模型子网格语义编辑；原网站访问权限保持不变。

## v8 组件创作与 Agent
`components.ts` 负责基础目录、自定义定义/实例、语义标签、预算验证、Agent 方案与提示词；`Studio.tsx` 提供编辑与方案预览。WorldEngine 构建声明式几何体、维护碰撞/选择/变换、导出同步后的实例。地图协议扩展可选字段兼容旧地图。

`server/agent.ts` 在私有 Sites 身份边界内调用 OpenAI Responses，并执行服务端验证；`agent-schema.ts` 是严格输出约束。真实密钥只读 Worker env。构建将 client 静态资产嵌入 ESM Worker，避免隐含的 ASSETS 绑定。开发预览通过 Vite 服务端中间件复用 API 实现。

WebMCP `preview_worldlab_scene` 只导入经校验的方案到可见预览，需在界面应用；不执行代码。服务端在缺少密钥时明确返回 503。云端素材仓库、多人协作、集中限流和自动布局验收尚未实现。
