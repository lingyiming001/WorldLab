# WorldLab · 认识世界

通过“感知 → 识别 → 观察 → 操作 → 概念 → 语言”探索现实事物的三维 Web 应用。当前版本为可运行的工程原型，不能视为已经完成工业级验收的产品。

## 运行

需要 Node.js 22.12+（建议 Node 24 LTS）。

```sh
npm ci
npm run dev
npm test
npm run build
```

打开终端打印的本地地址。生产输出在 dist。没有后端账户依赖。Sites 默认私有部署。

## 已实现

- 程序化校园地图：三层教学楼、入口广场、操场篮球场、动画柴犬，以及房屋、树木、水面、长椅、小球。
- 鼠标环绕、缩放、射线选择；第一人称 WASD 移动、拖动转向、Shift 加速、Esc 退出。
- 物体移动 / 旋转 / 缩放操纵器；聚焦物体与重置视角。
- 重力与反弹简化演示（9.81 m/s²，恢复系数 0.62）。
- 概念观察台、中英文名称与解释、浏览器本地学习进度。
- 本地自包含 GLB 2.0 导入、附带开源小鸭示例、模型自适应尺寸、模型动画播放。
- WebGL 不可用反馈、加载失败反馈、输入大小与外部资源校验、GPU 清理。

## 使用

在左侧或场景中选择物体，点击右侧观察按钮探索概念；小球的观察按钮会释放小球。使用场景左侧工具改变所选物体，拖动红绿蓝坐标轴。进入漫游后使用 WASD 移动、鼠标拖动转向，点击中央瞄准的物体可以选择。移动设备使用触摸环绕与缩放，第一人称主要面向键鼠设备。

模型库支持本地 .glb 文件（不上传，最大 30 MB），不支持外部 buffer / texture、Draco 和 KTX2。自定义模型与变换不持久化；学习进度仅保存在当前设备。刷新后恢复内置世界。导入模型没有自动生成的语义与课程。

## 校园地图更新

右上角校园地图可点击学校、操场、小狗与房屋聚焦观察；动物使用程序化小狗模型，互动按钮触发约 4.5 秒摇尾动画。学校为外观模型，含教学楼、入口台阶、双语校牌、时钟与旗杆，尚不包含可进入的教室。内置概念总数为 13，探索进度沿用原有设备记录。

## 人物探索与环境语言

默认打开第一人称探索，WASD / 屏幕方向按钮移动，鼠标或手指拖动转向，点击 / 轻触物体或按 E / 点击“触碰”识别准星指向的物体。名称气泡锚定在实际触碰的模型上，随相机和物体位置更新，移出视野时隐藏，可手动关闭。

顶部“环境语言”独立于界面语言，目前支持中文与 English，并记住设备上的选择。切换环境语言会立即改变现有气泡与地图中的物体名称。内置物体有双语词条；未提供双语名字的导入模型沿用文件名。

漫游时收起目录和观察台；校园地图可直接走近地点，保持人物视角。点击“俯瞰与编辑”恢复目录、模型编辑与概念面板。当前不包含语音朗读；房屋已有基础墙体 / 家具碰撞，尚未接入完整物理引擎。

## 可进入房屋

地图中点击房屋走到门前，选择“开门”后用 WASD / 方向按钮步行通过门洞，或选择“进入房屋”自动开门并进入客厅。房门也可直接触碰开关。客厅包含沙发、桌子、书、落地灯，都支持环境语言气泡；触碰落地灯或气泡中的开关可以改变局部照明。室内的“走出房屋”先打开门再返回室外。

第一人称视野为 70 度，俯瞰为 45 度。房屋的墙、房门和主要家具阻挡人物移动；此碰撞只覆盖该房屋，不代表其他模型已有完整碰撞。学校仍为外观场景。

新增 src/interior.ts 及 src/interior.test.ts，自动验证关闭入口、打开门洞、墙体、变换后的碰撞与物体标识。

## 本轮场景升级

学校主楼宽 25、高 9.6，配双侧翼、三层窗带、玻璃门厅、雨棚、台阶与栏杆。房屋窗户有真实开口和透明玻璃，可以单独向外推开；门旁绿色墙壁开关控制顶灯，米色开关控制台灯和落地灯。进入房屋后点击“墙上开关”即可走近观察。

柴犬使用 Quaternius 的 CC0 骨骼模型，随包部署，播放 Gallop / Idle 动画。自动在校园选择路线、绕开建筑与树木，在路径之间短暂停留；小地图跟随位置。模型为风格化三维资产。

## 学校内部探索

点击小地图学校 → 进入学校。主楼三层都有教室、桌椅、走廊与楼层标牌；沿中央楼梯使用 WASD 或方向按钮上下楼。上楼楼梯 / 下楼楼梯按钮带到当前层的楼梯平台，需自己走台阶切换楼层；也可以从侧边走廊绕到下一段楼梯。墙体、上层窗玻璃、家具与护栏阻挡人物，楼板和台阶支撑人物高度，楼梯井边缘不可直接踏空。两侧翼楼目前封闭。

## 地图库、文件分享与识别粒度

顶部“地图库”支持进入内置地图、新建当前世界的副本、编辑地图信息、保存在本机、下载与导入 `.worldlab.json`。地图储存在浏览器 IndexedDB，模型也随地图保存；共享使用系统文件分享，浏览器不支持时下载文件，由用户自行发送。接收方在可访问的 WorldLab 中导入；网站当前仍保持私有访问，地图文件不授予网站权限。

创建者为每个物体设置中英文名称与是否单独识别。操场 → 篮球架 → 篮圈可以逐级启用；禁用部件标签时使用最近的已启用父级名字。也可以只认识整体。标签粒度不关闭开门、灯光等物理交互。现有层级对应内置部件及导入模型整体；尚无任意 GLB 网格部件的标注工具。

导出包含受支持场景对象的变换、可见性、语言、标签、创建者信息和自包含 GLB / 许可文本。世界采用本版本内置校园作为基础，不包含应用程序；操作中的门、窗、灯状态不作为地图运行时存档。地图格式与限制见 docs/MAP_FORMAT.md。

## 场景创作与 Agent（v8）
顶部「创作场景」打开可视工作台，提供 9 种基础组件：树木、长椅、桌子、椅子、墙体、地板、箱子、球体、花盆。支持空白场景、实例复制/删除、数值或三轴变换、中英文名称、整体/部件识别、单步撤销（当前会话）、地图保存与分享。组件定义与实例均包含在地图 JSON 中；组件还可单独导出导入。

「Agent 创作」通过服务端 OpenAI Responses API 生成结构化场景或组合组件。服务端与客户端均验证组件引用、数量、尺寸和坐标；用户查看清单后应用。没有配置密钥时按钮禁用并明确提示；公园示例是预制方案，不是实时 AI 生成。真实 AI 调用尚未验收，需安全配置密钥后完成。参见 [Agent 配置](docs/AGENT_SETUP.md) 与 [创作协议](docs/COMPONENT_FORMAT.md)。

构建现在同时产出 `dist/client` 和 Cloudflare ESM Worker `dist/server/index.js`。Worker 包含构建后的静态资源，API 和前端同源。密钥只通过服务端环境读取，禁止使用 `VITE_` 前缀。
